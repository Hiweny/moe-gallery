# MoeGallery

一个用于整理、测试和调用随机图片 API 的前端项目，同时提供独立的 API 文档与实测报告。

> 当前 README 按 2026-07-28 之后的 v9 版本整理。

## 当前功能

- 二次元、动漫角色、真人写真、JK、黑丝、白丝等随机图片接口整理
- API 返回方式、速度、分辨率与稳定性实测记录
- 独立 API 文档页面
- Service Worker 代理与接口回退
- 真实图片 URL 收藏
- IndexedDB 本地持久化
- 横竖屏适配
- 滑动方向提示与移动端手势优化
- 敏感词脱敏

## 使用

直接打开 `index.html` 即可运行前端页面，也可以部署到 GitHub Pages 等静态托管服务。

项目中的随机图片接口来自第三方服务，稳定性、速度、防盗链策略和内容可能随时变化。README 中的测试结果仅代表测试时的情况，不保证长期有效。

## 说明

这个仓库目前更偏向“随机图 API 工具 + 实测资料库”，而不是一个需要后端数据库的传统图片网站。
